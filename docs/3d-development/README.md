# Документация вертикальной лаборатории

Параметры опыта и принцип устройства заданы в [AGENTS.md](../../AGENTS.md) из `origin/master`. [План проекта](../../plan.md) фиксирует состояние текущего сайта и общие этапы работы. Документы ниже описывают подготовку новой 3D-модели.

| Документ | Содержание |

| [Техническая спецификация](installation.md) | Несущая рама, узлы и материалы, номинальные размеры, сборочные координаты и проверка подвеса |
| [План моделирования](modeling-plan.md) | Визуальное решение, последовательность моделирования, интеграция и приёмка |

| [Измерительная система V3](measurement-v3.md) | Реальные аналоги, датчики PH0731, эскизы с частотомером и осциллографом, проверки прототипа |
| [Сцена V3.1](laboratory-v3-1.md) | Предварительная сборка варианта B, сцена Blender, девять ракурсов, проверки зазоров, точки привязки и предположения |
| [Контракт Blender → GLB](blender-glb.md) | Коллекции, имена привязок, масштабы, центры поворота, экспорт и загрузка в Three.js |
| [Аудит текущего сайта](site-audit.md) | Проверенная версия, результаты тестов, наблюдения о прототипе, границы интеграции и дефект секундомера |
