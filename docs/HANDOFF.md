## Принятые решения

- Рабочий пролёт ограничен точками `A` и `B` до начала дуги на ролике. Физика описывает основную моду с неподвижными концами, стальные струны диаметром 0,3–0,5 мм и подвесы 100–300 г. Согласованные константы, затухание, формулы и девять эталонов приведены в [физической спецификации](physics.md).
- Экспорт для браузера разделяет стенд и отдельные грузы. Blender использует метры, `+Z` вверх, а преобразование точек в GLB — `(x, z, −y)`. Имена и локальные начала колёс, грузов, опор и дисплеев входят в контракт. Рабочий пролёт и хвост будут формироваться в браузере по привязкам. [Контракт GLB](blender-glb.md)
- Модель колебаний и измерения используют общие часы физического времени. Частотомер находит шесть пересечений равновесия в одном направлении для пяти периодов, а отсчёты модели не зависят от кадров. В режиме ×40 фаза, секундомер и физический тон остаются согласованными. [Приборы и время](physics.md#приборы-и-время)
- Для будущего приложения согласованы React, TypeScript, Vite, Three.js, React Three Fiber и Drei. Геометрия обновляется в 3D-сцене, интерфейс получает выбор и состояния приборов через React, показания DOM-панели и 3D-дисплея имеют общий источник. Модульные проверки запланированы в Vitest, браузерные — в Playwright, размещение — на Vercel. Версии пакетов будут зафиксированы при создании приложения.

## Blender MCP

Если инструменты Blender уже доступны в агенте и успешно читают сцену, используйте существующее подключение. Для ручной настройки установите `uv` и убедитесь, что `uvx` доступен из того же окружения, в котором запускается клиент. В обычной оболочке, где есть доступ к сети, выполните:

```sh
uvx mcp-for-blender install-addon
```

В Blender включите **Edit → Preferences → Add-ons → Interface: MCP for Blender**. На панели `N` во вкладке MCP for Blender проверьте состояние соединения и при необходимости запустите сервер. Сначала откройте нужную копию сцены и проверьте статус дополнения и имя сцены через инструменты чтения. Для этого этапа достаточно локального соединения. [Инструкция MCP for Blender](https://github.com/ahujasid/mcp-for-blender)

**Codex.** Зарегистрируйте локальный stdio-сервер через CLI. Конфигурация сохраняется в пользовательском `config.toml` Codex. Если рабочий стол или IDE не видит `uvx`, задайте полный путь к своему исполняемому файлу в конфигурации. После настройки начните новый сеанс в корне проекта. [Настройка MCP в Codex](https://developers.openai.com/codex/mcp)

```sh
codex mcp add blender -- uvx mcp-for-blender
codex mcp list
```

**Claude Code.** Выполните команды из корня нужного рабочего дерева. Область `local` сохраняет регистрацию для этой копии проекта в пользовательских настройках Claude Code. Проверьте соединение через `/mcp`, а импорт общих требований — через `/memory`. [Настройка MCP в Claude Code](https://code.claude.com/docs/en/mcp), [импорт инструкций](https://code.claude.com/docs/en/memory)

```sh
claude mcp add --scope local --transport stdio blender -- uvx mcp-for-blender
claude mcp list
```

Если сервер запускается, но сцена недоступна, проверьте, что Blender открыт, дополнение включено, а версии дополнения и MCP-пакета совместимы. Обновляйте их вместе по руководству поставщика. При работе с одним файлом оставьте одного редактора сцены. Используйте локальные пути в пользовательских настройках клиента, а для файлов проекта — относительные пути.

## Воспроизведение и проверка

Команды выполняются из корня репозитория. `blender` должен быть доступен в PATH, либо укажите путь к исполняемому файлу. Просмотр готового файла не требует `uvx`, MCP или шрифта. Генератор ищет системный кириллический шрифт. Если подходящего шрифта нет, передайте путь к доступному кириллическому TTF через `--font`. Для сравнения формы надписей используйте тот же шрифт, что и при выпуске, Segoe UI. Файл шрифта в репозиторий не входит.

```sh
# Проверка сохранённой модели и пробный экспорт
blender --background --factory-startup --disable-autoexec assets/blender/prototype.blend --python-exit-code 1 --python assets/blender/check_prototype.py -- --glb

# Пересборка в отдельный файл
blender --background --factory-startup --disable-autoexec --python-exit-code 1 --python assets/blender/build_prototype.py -- --output prototype-rebuilt.blend
blender --background --factory-startup --disable-autoexec prototype-rebuilt.blend --python-exit-code 1 --python assets/blender/check_prototype.py -- --glb

# Переснять шесть ракурсов в отдельную папку
blender --background --factory-startup --disable-autoexec assets/blender/prototype.blend --python-exit-code 1 --python assets/blender/render_prototype.py -- --output prototype-render
```

Для пробного GLB скрипт создаёт два файла во временной папке и удаляет их по завершении. Для быстрого рендера можно передать `--percentage 35`. После проверки удалите локальные выходные файлы или держите их вне рабочего дерева.

## Открытые вопросы и следующий этап

- Согласовать способ выделения тонкой струны и полезный ракурс измерения. Проверить, насколько легко увидеть все каналы, ролики, грузы и показания приборов.
- Принять решение о последних 30 мм шкалы и повторить проверку зазора в канавке ролика после детализации.
- Для GLB сохранить отдельные интерактивные узлы и точки в допуске 0,5 мм. Прогнать валидатор и браузерную проверку двух пакетов. Целевой бюджет — до 3 МБ суммарно, до 70 тыс. видимых треугольников и около 80 вызовов отрисовки стенда в общем виде.
- Реализация физики должна пройти девять эталонных комбинаций, проверить неподвижность концов и погрешность датчика не выше 1% в обычном режиме и ×40. Приёмка полной лаборатории включает ручной отсчёт, звук, таблицу, управление и открытие сайта по ссылке. [Критерии](../AGENTS.md#этап-и-приёмка)

После согласования команда может назначить независимые задачи. Один участник ведёт детализацию `.blend` и подготовку GLB, второй — модуль колебаний, часы, частотомер и Vitest, третий — браузерную сцену и управление камерой по контракту осей и имён. Панель приборов, график и таблицу можно готовить параллельно после согласования интерфейса состояния. Playwright-сценарии для девяти опытов подключаются после интеграции сцены и приборов.
