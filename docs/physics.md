# Физика опыта и эталонные измерения

## Исходные параметры и формулы

Модель описывает три однородные круглые стальные струны. У каждой рабочий пролёт `L = 0,600 м`, два неподвижных конца и плотность материала `ρ = 7850 кг/м³`. Подвесы вместе с держателем имеют массу 0,100, 0,200 и 0,300 кг. При `g = 9,81 м/с²` им соответствуют натяжения 0,981, 1,962 и 2,943 Н.

- Площадь сечения `S = πd²/4`, линейная плотность `μ = ρS`.
- Натяжение `T ≈ mg` задаёт груз за идеальным роликом. Для расчёта оно постоянно в течение одного опыта.
- Скорость поперечной волны `v = √(T/μ)`, длина волны основной моды `λ₁ = 2L = 1,200 м`, основная частота идеальной струны `f₁ = v/(2L)`.
- Неподвижные точки находятся при `x = 0` и `x = L`. Пучность находится при `x = L/2 = 0,300 м`.

Эти зависимости проверены по учебному описанию стоячих волн и натяжения подвешенной массой. [OpenStax, Standing Waves and Resonance](https://openstax.org/books/university-physics-volume-1/pages/16-6-standing-waves-and-resonance)

## Затухание первой моды

Коэффициент `β = 2 с⁻¹` применяется к огибающей амплитуды. Для щипка с отпусканием без начальной скорости проектная модель описывается следующим образом.

```text
ω₀ = 2π f₁
ωd = √(ω₀² − β²)
fd = ωd / (2π)
q(t) = A₀ e^(−βt) [cos(ωd t) + (β/ωd) sin(ωd t)]
u(x,t) = q(t) sin(πx/L)
```

`A₀` — смещение середины со знаком в момент отпускания, `|A₀| ≤ 0,010 м`. При `t = 0` модель даёт `q = A₀` и `q′ = 0`. Концы работают как идеальные опоры. Максимальный наклон около 0,052 рад согласуется с учебным приближением малых наклонов. Реальная стальная проволока также имеет изгибную жёсткость и статический провис, а ролик — трение. Эти факторы находятся за пределами принятой модели. Допуск 1% относится к частотомеру относительно симуляции.

## Приборы и время

Один источник времени задаёт все фазы опыта. В обычном режиме приращение физического времени равно прошедшему активному времени, в режиме «Замедление ×40» оно делится на 40. Смена скорости сохраняет текущее физическое время и фазу. При скрытии вкладки предложено приостанавливать опыт, часы и звук до возвращения пользователя.

| Прибор | Поведение |
|---|---|
| Частотомер | Считывает смещение при `x = 0,300 м`. От первого до шестого пересечения нуля в одном направлении проходит пять полных периодов. Показание равно `5/(t₆ − t₁)`. Проектный шаг опроса 0,5 мс времени модели, пересечения уточняются линейной интерполяцией. При опросе за кадр обрабатывать все пропущенные отсчёты модели по порядку. |
| Индикация частотомера | «Готов», «Измерение», затем значение в Гц. Погрешность `100 × |fизм − fd| / fd ≤ 1%` во всех девяти сочетаниях. При сигнале ниже порога до завершения замера показать «Сигнал слишком слабый». Порог 0,15 мм по амплитуде предложен для предварительной проверки. |
| Секундомер | «Пуск», «Стоп», «Сброс». Пользователь считает полные колебания между одинаково направленными пересечениями равновесия и вводит `N` для расчёта `N/Δt`. Отображение физического времени предложено до 0,001 с. |
| График | Горизонтальная ось «Время модели, с», вертикальная «Смещение, мм». Источник — та же средняя точка. Сохранять экстремумы при уменьшении числа отображаемых отсчётов. |
| Таблица | Номер опыта, диаметр, масса, расчётная и автоматическая частоты, число периодов, время по секундомеру, ручная частота и отклонение от расчётной. Пустое поле используется для результата, который ещё не получен. |
| Звук | Тон `fd` с затухающей громкостью и переключателем. Частота тона остаётся физической в режиме ×40. Проектный вариант сохраняет синхронное начало тона и визуального движения, а громкость следует огибающей физического времени. Для 21–30 Гц слышимость зависит от динамиков. |

Пять периодов занимают 0,082–0,238 с физического времени или 3,30–9,51 с при замедлении ×40, плюс ожидание первого пересечения. Новый щипок запускает замер датчика и новый след на графике. Смена струны или груза сбрасывает датчик, график и секундомер. Накопленные строки таблицы сохраняются в рамках сеанса.

## Предмет проверки

На этапе проектирования независимый пересчёт подтвердил все девять строк. Для контрольного сигнала с оттягиванием 10 мм оценка частоты по пересечениям с шагом 0,5 мс проверена во всех сочетаниях при 20, 60 и 144 кадрах/с и обоих масштабах времени. Максимальная относительная ошибка в этих 54 расчётных сценариях составила 0,00030%. Допуск к будущей реализации остаётся 1%.

- Vitest проверяет девять частот, два узла, начальную скорость, ограничение амплитуды, убывание огибающей и отношения частот.
- Отдельно проверяется погрешность частотомера при разных графиках кадров и обоих масштабах времени, сброс незавершённых замеров и обработка слабого сигнала.
- Playwright проходит все девять опытов, проверяет отображение результатов, график, секундомер, таблицу, замедление и переключение звука. Возможность вручную сосчитать периоды проверяется человеком при осмотре.
