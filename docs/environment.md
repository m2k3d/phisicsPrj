# Рабочее окружение

Первичная проверка выполнена 26 ноября 2026 года в Windows из основного репозитория «Проект физика 2», до сборки предварительной сцены. Результаты проверки готовой сцены и GLB приведены в [отчёте о прототипе](prototype.md#проверка) и [передаче проекта](HANDOFF.md#результаты).

## Blender MCP

- Blender 5.3.0, дополнение 2.0, текущий и ожидаемый протокол 16.
- Чтение сцены вернуло несохранённую `Scene` с кубом, камерой и источником света. Текущие единицы **Metric**, масштаб 1.0.
- Проверка RNA обнаружила оператор `bpy.ops.export_scene.gltf` и его параметры выбора объектов, оси +Y Up, экспорта дополнительных свойств, камер и света. Пробный GLB предстоит получить после выбора конструкции и создания предварительной сцены.
- Для проверки использовались статус, сведения о сцене и чтение RNA. Моделирование и экспорт не запускались.

## Причина сбоя npm

| Проверка | Результат |
|---|---|
| `npm.cmd config get registry` | Настроен публичный HTTPS-реестр `registry.npmjs.org` |
| `npm.cmd config get strict-ssl` | `true` |
| DNS | Успешное разрешение записей A и AAAA |
| HTTPS внутри песочницы Codex | curl сообщает отказ при подключении к TCP 443, включая принудительный IPv4. Node HTTPS возвращает `EACCES` для `registry.npmjs.org`, `www.npmjs.com` и `nodejs.org` |
| `npm.cmd --logs-max=0 --fetch-retries=0 --fetch-timeout=5000 ping` внутри песочницы | `EACCES` при обращении к публичному HTTPS-эндпоинту |
| Те же проверки через разрешённое выполнение вне песочницы | HTTPS HEAD возвращает HTTP 200. npm получает `PONG` за 891 мс |

Причина воспроизводится в режиме стандартной песочницы Codex. Она блокирует исходящее HTTPS-соединение до рукопожатия TLS. В разрешённом сеансе на этой же машине конфигурация npm успешно подключается к реестру. Для этапа установки можно использовать обычную оболочку Windows с сетевым доступом или разрешённое выполнение команды установки из Codex.

Во время проверки `strict-ssl` оставался включённым. Диагностические команды не устанавливали зависимости и не меняли параметры npm либо системные настройки безопасности.
