# Прототип открытого стенда

Модель варианта A собрана в Blender 5.3 через Blender MCP. Сохранена одна рабочая сцена `Standing Wave Lab - Prototype A` с 240 объектами, восемью коллекциями и семью камерами. В демонстрационной сборке груз 200 г подвешен к передней струне S1, а грузы 100 и 300 г стоят в лотке. У всех трёх грузов предусмотрены отдельные места в лотке и посадка на любую из трёх струн.

Общий вид использует положение камеры из спецификации и вертикальный угол 38°. Спереди и сверху доступны ортографические виды. Остальные камеры перспективные. `CAM_MEASURE` сохраняет заданный в спецификации ракурс для наблюдения пучности. На контрольном кадре приборов используется поднятая камера `CAM_INSTRUMENTS`. Мягкое освещение выделяет стальные нити, а материалы разделяют матовый алюминий рамы, графитовые каналы, стальные детали, пластик и лабораторный ламинат. Показания на дисплеях нанесены для проверки читаемости.

Таблички, шкалы и значения созданы как меши с русскими надписями. Колёса имеют собственные центры на осях роликов, а парковочные клипсы — отдельные шарниры. Узлы грузов хранят массу сборки в граммах. Положение грузов относится к демонстрационному кадру.

## Координаты привязок

Blender использует метры, `+X` идёт к ролику, `+Y` к заднему борту, `+Z` вверх. Столешница находится на `Z = 0`. Ниже числовые координаты относятся к сцене и приведены в метрах в порядке `X / Y / Z`.

| Окончание имени точки | `STR_01_*`, Ø0,3 мм | `STR_02_*`, Ø0,4 мм | `STR_03_*`, Ø0,5 мм |
|---|---|---|---|
| `A` | 0 / −0,085 / 0,160 | 0 / 0 / 0,160 | 0 / 0,085 / 0,160 |
| `B` | 0,600 / −0,085 / 0,160 | 0,600 / 0 / 0,160 | 0,600 / 0,085 / 0,160 |
| `MID` | 0,300 / −0,085 / 0,160 | 0,300 / 0 / 0,160 | 0,300 / 0,085 / 0,160 |
| `PULLEY_AXIS` | 0,600 / −0,085 / 0,135 | 0,600 / 0 / 0,135 | 0,600 / 0,085 / 0,135 |
| `TANGENT_OUT` | 0,625 / −0,085 / 0,135 | 0,625 / 0 / 0,135 | 0,625 / 0,085 / 0,135 |
| `HOOK` | 0,625 / −0,085 / 0,090 | 0,625 / 0 / 0,090 | 0,625 / 0,085 / 0,090 |
| `SENSOR` | 0,300 / −0,062 / 0,163 | 0,300 / 0,023 / 0,163 | 0,300 / 0,108 / 0,163 |

Ролик вращается вокруг локальной оси `Y` Blender, соответствующей направлению `−Z` при экспорте с `+Y Up`. Радиус траектории оси струны в канавке равен 25 мм. Внешний диаметр колеса 52 мм. После дуги в 90° хвост опускается на 45 мм к точке `HOOK`.

## Проверка

- Подтверждены размеры стола, панели и корпуса приборов, глубина каждой прорези 8 мм, пролёты 600 мм и три физических диаметра. Торцы мешей совпадают с точками A, B и HOOK. На виде сверху и в крупном плане различаются все три струны.
- Для оттягивания 10 мм проверен зазор между нижней кромкой струны и верхней поверхностью панели. Минимум **24,75 мм** для Ø0,5 мм. На подходе к ролику проверено положение струны по сечению канавки. У осей и стержней смоделированы сквозные отверстия.
- Любой груз можно поставить в любую точку `HOOK`. Контрольные положения дают **38 мм** от плоскости правого края стола до ближайшей грани груза и **30,5 мм** от низа груза до плоскости столешницы. Высота сборок примерно 63,4 мм. Свободные гнёзда и держатели доступны на общем и верхнем видах.
- Сцену повторно собрали из скрипта в отдельном запуске Blender и проверили заново после открытия. Публикуемая копия собрана с заводскими настройками и без внешних ссылок на ресурсы. Надписи остались мешами. Повторно отрисованы все шесть контрольных ракурсов в уменьшенном разрешении.
- Пробные пакеты GLB 2.0 содержат 45 873 треугольника, в сумме около 1,63 МБ. Проверены координаты точек, ориентация, отдельные грузы и ролики. Студия и временные струны исключаются из экспортного набора. [Подробности проверки](HANDOFF.md#результаты)

## Замечания перед детализацией

| Наблюдение | Предложение |
|---|---|
| Струна 0,3 мм становится субпиксельной при общем виде на небольшом экране. В строго фронтальном ракурсе три пролёта проецируются друг на друга | Сохранить физические диаметры. В браузере выделять активный канал, подсвечивать точку захвата, применять более широкую невидимую область указателя и отдельный ракурс измерения |
| На боковом крупном плане задний датчик частично перекрывает частотомер | Добавлен поднятый ракурс «Приборы». В интерфейсе показания также выводятся в русскоязычной панели, как предусмотрено спецификацией |
| Зазор у касания струны с канавкой чувствителен к профилю ролика | Повторить проверку хода 10 мм после изменения профиля или числа секций колеса |
| Последние 30 мм шкалы выступают за край панели до точки B | Подтвердить жёсткость консольного вылета либо добавить крепёж под торец вне пути ролика |
| Пробные GLB имеют 180 примитивов на экземплярах мешей до отсечения невидимых частей. Это больше целевого бюджета около 80 вызовов отрисовки | При подготовке рабочих GLB объединить статические шкалы, таблички и крепёж по материалу. Сохранить отдельные интерактивные узлы и проверить фактические вызовы отрисовки в браузере |

Для замены геометрии Three.js берёт координаты `A` и `B`, а для продолжения за роликом — `PULLEY_AXIS`, `TANGENT_OUT` и `HOOK`. Меши предварительных струн помечены свойством `replace_with_runtime`. Пакеты экспорта и принятый масштаб описаны в [конвейере GLB](blender-glb.md).

## Воспроизведение

Из корня репозитория запустить Blender 5.3. Путь к исполняемому файлу понадобится явно, если Blender отсутствует в PATH. При необходимости передать генератору `--font` с локальным кириллическим шрифтом. Сгенерированные надписи сохраняются в виде геометрии.

```powershell
blender --background --factory-startup --python-exit-code 1 --python assets/blender/build_prototype.py -- --output assets/blender/prototype.blend
blender --background assets/blender/prototype.blend --python-exit-code 1 --python assets/blender/check_prototype.py -- --glb
blender --background assets/blender/prototype.blend --python-exit-code 1 --python assets/blender/render_prototype.py
```

Для проверки пробные GLB создаются во временной папке. Контрольные изображения сохраняются в `assets/blender/previews`.
