# Проектирование лабораторной установки

**Утверждён вариант A с открытой алюминиевой рамой.** Предварительная модель собрана в Blender и передана на согласование. На ней проверены три стальные струны длиной 600 мм, путь через ролики, крепления приборов и просвет подвешенного груза.
